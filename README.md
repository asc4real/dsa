# 1000 DSA Exercises in Python

A progressive DSA practice roadmap with **1,000 exercises**, organized by topic.

## How to Use This Roadmap

For every exercise:

- [ ] Solve it yourself first
- [ ] Write the brute-force approach
- [ ] Write the optimized approach
- [ ] Calculate time complexity
- [ ] Calculate space complexity
- [ ] Write at least 3 test cases
- [ ] Note important edge cases

A useful structure for each solution:

```python
def solution(...):
    ...
```

And make sure you can explain:

1. What is the brute-force approach?
2. Why is it inefficient?
3. What pattern can improve it?
4. What data structure should I use?
5. Why does the optimized algorithm work?
6. What is the time complexity?
7. What is the space complexity?
8. What edge cases should I test?

# Pattern Recognition Checklist

Before coding, ask:

```text
Is the input sorted?
    → Binary Search / Two Pointers

Do I need fast lookup?
    → HashMap / Set

Do I need a contiguous range?
    → Sliding Window / Prefix Sum

Do I need next greater/smaller?
    → Monotonic Stack

Do I repeatedly need min/max?
    → Heap / Monotonic Queue

Is this hierarchical?
    → Tree / DFS / BFS

Is this relationships or connectivity?
    → Graph / DFS / BFS / DSU

Do I need all combinations?
    → Backtracking

Are there overlapping subproblems?
    → Dynamic Programming

Am I minimizing/maximizing a feasible answer?
    → Binary Search on Answer

Do I repeatedly query ranges?
    → Fenwick Tree / Segment Tree
```

# Final Goal

The objective is **not** merely to complete 1,000 problems.

The real goal is to look at an unfamiliar problem and quickly recognize patterns such as:

```text
Problem
    ↓
Input characteristics
    ↓
Constraints
    ↓
Possible data structure
    ↓
Algorithmic pattern
    ↓
Optimized solution
    ↓
Time + space complexity
```

For example:

```text
Two Sum
    ↓
Unsorted array
    ↓
Need complement lookup
    ↓
HashMap
    ↓
O(n) time
```

instead of immediately writing:

```python
for i in range(n):
    for j in range(i + 1, n):
        ...
```

That pattern-recognition skill is what makes DSA useful in real interviews and engineering work.
